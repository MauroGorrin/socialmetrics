# Lead Generation System

Sistema de atracción de clientes vía content marketing + web + Instagram.

## Objetivo
Convertir tu expertise en **leads calificados** de empresas que necesitan gestión de ads (Meta, Google, LinkedIn).

## Componentes

### 1. Content Pillars (Temas Base)
Define 5 temas principales que resuelven problemas de tu target:
- Ej: ROAS bajo, CPL alto, problemas con iOS 14, escalado de ads, etc.

### 2. Content Types
- **Posts Instagram**: 3/semana (cortos, puntuales, enfoque problemas)
- **Artículos Blog**: 2/semana (profundos, SEO, thought leadership)
- **Landing pages**: Para capturar leads específicos

### 3. CTAs (Calls-to-Action)
Cada pieza debe llevar a:
- Reservar consultoría gratuita
- Email list
- Whatsapp
- Demo de caso de estudio

### 4. Distribución
- Instagram feed + Stories
- Blog (link en bio)
- Email a base de suscriptores
- LinkedIn (tu perfil + página)

## Métrica de Éxito
- Leads cualificados/mes
- Conversión de lead → cliente
- ROI de tiempo invertido en content
